## 🎯 The Problem

92% of New Year's resolutions fail by February. Why? Because motivation is a finite resource, life is unpredictable, and most "trackers" are just passive digital graveyards of unfulfilled intent. They don't account for your existing workload, they don't adapt when you stumble, and they provide zero tactical guidance. You aren't failing because of a lack of will; you're failing because of a lack of a system that breathes with you.

## ✨ Key Features

### 🤝 Negotiation Agent (Reality Check)
Don't set yourself up for failure. When you create a resolution, our AI negotiates your cadence based on your skill level and *other active resolutions*. If you're a beginner wanting to hit the gym 7x a week while also learning Mandarin, NeuroResolv will step in to suggest a sustainable 3x/week start.

### 🗺️ Flexible Roadmap Systems
Choose how you grow:
- **AI-Personalized:** A multi-milestone journey generated by Gemini 2.5 Pro tailored to your specific goal.
- **Manual Control:** Build your own milestones from scratch.
- **Pure Tracking:** Skip the roadmap and just use our advanced streak mechanics.

### 🎙️ Multi-Modal Check-ins
Log your progress via **Text, Audio, or Video**. Whether it's a quick note, a voice reflection, or a video of your workout, our AI processes the content to confirm progress without storing your private media.

### 🛡️ Resilience & Stickiness
- **Streak Shield:** Earn shields through consistent check-ins. Life happens; use a shield to protect your streak when it does.
- **Streak Pause:** Planning a trip or need a mental health break? Pause your journey without losing your momentum.
- **Accountability Groups:** Link with up to two friends. Shared streaks mean shared responsibility—if one falls, the joint streak breaks.

### 🧠 MCP Support
NeuroResolv provides MCP (Model Context Protocol) support, allowing you to integrate with AI agents like Gemini to enhance your productivity.

### 📧 Intelligent Reflections
Receive carefully timed emails for milestones, encouragement during inactivity, or a "welcome back" summary when resuming from a pause.

## 📊 Opik: The Data Flywheel & Guardrails

NeuroResolv isn't just "using AI"—it's an **Observability-First** application. We leverage Opik (by Comet) to build a self-improving system:

- **Feedback-Driven Optimization:** When a user gives a "Thumbs Down" to an AI roadmap, the feedback is logged to Opik. A weekly optimizer uses Opik's `MetaPromptOptimizer` to refine our system prompts automatically.
- **User-Centric Tracing:** We track every LLM interaction with custom user-metadata tags, allowing us to retrieve specific reflection histories to determine milestone completions.
- **Online Evaluations:** Every LLM response is automatically checked for Hallucination, Relevance, and Output Adherence using Opik's evaluation suites.
- **Operational Excellence:** Slack alerts for latency breaches, budget thresholds, and error spikes ensure a production-grade experience.

## 🚀 Quick Start

1. **Clone & Setup:** `cp backend/.env.example backend/.env`
2. **Add Keys:** Add `GOOGLE_API_KEY` and `OPIK_API_KEY` to `.env`.
3. **Run:** `docker-compose up --build`

> If you see errors related to Opik, then navigate to `backend/opik` and run `./opik.sh` to start the Opik server. The code when running locally preferes locally running Opik server.

## 🚀 Quick Start

### Prerequisites
- Python 3.12
- Node.js 20+
- Docker & Docker Compose (optional but recommended)

### Option 1: Docker Compose (Recommended)

```bash
# Clone the repository
git clone https://github.com/yourusername/neuroresolv.git
cd neuroresolv

# Create your .env file
cp backend/.env.example backend/.env
# Edit backend/.env and add your API keys

# Start everything
docker-compose up --build

# Frontend: http://localhost:3000
# Backend API: http://localhost:8000
# API Docs: http://localhost:8000/docs
```

### Option 2: Manual Setup

#### Database
```bash
# Start postgres container
docker run -e POSTGRES_PASSWORD=postgres -dp 5432:5432 postgres:16
```

#### Backend
```bash
cd backend

# Install Poetry if you haven't
pip install poetry

# Install dependencies
poetry install

# Create and configure .env
cp .env.example .env
# Add your GOOGLE_API_KEY and OPIK_API_KEY

# Run the server
poetry run uvicorn main:app --reload

# API available at http://localhost:8000
```

#### Frontend
```bash
cd frontend

# Install dependencies
npm install

# Run development server
npm run dev

# App available at http://localhost:3000
```

## 🔑 Configuration

Create a `backend/.env` file with your credentials:

```env
# Required for AI features
GOOGLE_API_KEY=your-gemini-api-key

# Required for LLM observability
OPIK_API_KEY=your-opik-api-key
OPIK_WORKSPACE=default
OPIK_PROJECT_NAME=neuroresolv

# Security
SECRET_KEY=your-production-secret-key
```
